# PoE Inspector

Локальная база данных и просмотрщик ресурсов Path of Exile 2 (читает `Bundles2` из Steam-установки, ничего не изменяет в игре).

## Запуск

```
python build_index.py      # один раз после каждого патча игры: индекс всех файлов -> poe2.db (~30 с)
python -c "import sys; from poe_inspector import store, catalog; s=store.Store('poe2.db'); catalog.build(s)"   # каталог предметов и монстров
python run.py              # веб-интерфейс на http://127.0.0.1:8765
```

## Что есть

- **Индекс** всех ~4,27 млн файлов (путь, бандл, смещение, размер) в SQLite.
- **Предметы** (BaseItemTypes) и **монстры** (MonsterVarieties) с цепочкой `.ao -> .sm -> .smd/.fmt` до 3D-модели.
- **3D-просмотр** (`.smd` v3, `.fmt` v9, LOD0) и экспорт в `.glb`. Цвет пока серый, без текстур и скелета.
- **Таблицы** `data/balance/*.datc64` (1023 шт.): просмотр и фильтр. Без `schema.min.json` колонки угадываются (только строки).
- **Файлы**: поиск по всем путям, просмотр текстовых форматов (`.ao`, `.sm`, `.mat` и др.), скачивание.

## Не сделано

- Текстуры/материалы (`.mat`, `.dds`), иконки предметов, скелеты и анимации (`.ast`).
- Старые версии `.smd` (1-2) и `.fmt` (4-8).
- Имена колонок таблиц: нужен `schema.min.json` из dat-schema (положить рядом с `run.py`).

Форматы описаны в `ref/docs_FORMATS.md` (заметки сторонних авторов, сверены с этой установкой).
