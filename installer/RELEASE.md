# Выпуск версии и автообновление

1. Поднять номер в `VERSION` (например `1.0.1`).
2. Собрать: `powershell -ExecutionPolicy Bypass -File installer\build_installer.ps1`. В `..\poe_inspector_build\out` появятся
   `PoE Inspector Setup <версия>.exe` (полный установщик), `app-update.zip` и `app-update.zip.sha256` (пакет обновления без Python).
3. На GitHub создать Release с тегом `v1.0.1` и приложить ВСЕ три файла (`app-update.zip` и `app-update.zip.sha256` обязательны,
   без контрольной суммы программа обновление не примет).
4. Программа проверяет `https://api.github.com/repos/<repo>/releases/latest` при запуске. Репозиторий задаётся в `update.json`:
   `{"repo": "владелец/репозиторий"}` (публичный). Если файла нет, автообновление выключено.
5. Пользователь видит плашку «Доступно обновление», нажимает «Скачать» (проверяется SHA-256), затем «Перезапустить»: файлы заменяются
   при следующем старте. Обновление меняет только код и веб-файлы; если менялись зависимости Python, нужен полный установщик.

Пользовательские данные (база, кэши) лежат в `<папка установки>\data` и при обновлении и удалении программы не трогаются.
